# Code of Conduct

We are committed to a respectful, inclusive, and constructive collaboration environment.

## Expected behavior

- Be respectful of people, time, and differing perspectives.
- Give specific, constructive technical feedback.
- Protect private project information, credentials, and proprietary material.
- Focus discussion on the work rather than personal characteristics.

## Unacceptable behavior

Harassment, discrimination, intimidation, personal attacks, deliberate disclosure of private information, or knowingly unsafe contributions are not acceptable.

## Enforcement

Until a public repository and named enforcement channel exist, report concerns through the project maintainer channel agreed for the repository. Public reports should not include sensitive personal or security details.
